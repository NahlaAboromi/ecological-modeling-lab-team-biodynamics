# SmartKinneret – Ecological Modeling Project

Interactive system for real-time monitoring and short-term prediction of Lake Kinneret conditions.

## Technologies
- Python
- PCA
- Kriging
- KNN Regressor
- Gradio
- Hugging Face Spaces
- Google Colab

## Description
SmartKinneret is an ecological modeling project that integrates real-time environmental data, spatial analysis, and short-term forecasting to support monitoring and safety decisions for Lake Kinneret.
